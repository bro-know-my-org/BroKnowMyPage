# Codex TUI 快捷键速查

> 已按 `codex-cli 0.149.1` 的 TUI 默认 keymap 复核。所有按键都可以用 `/keymap` 重映射，没绑默认键的功能（比如 Fast mode）也能自己加上。
>
> 2026-08-28 的 `main`（`7d6f808b`）又补了一批 Vim 动作；下表已收录并标明它们尚未随 `0.149.1` 发布。

## 全局 / 主界面

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+T` | 打开 / 关闭 transcript 面板 |
| `Ctrl+G` | 用外部编辑器打开当前草稿 |
| `Ctrl+O` | 复制上一条回复为 Markdown |
| `Ctrl+L` | 清空终端并开始新会话（等同 `/clear`） |
| `Alt+A` | 打开 app-server 中所有 Agent 会话的总览 |
| `Alt+R` | 切换原始滚动模式（方便终端选中复制） |
| `Ctrl+/` | 在侧边对话和主对话之间切换（部分终端里是 `Ctrl+7`） |
| `Esc` | 中断当前正在进行的任务 |
| `Alt+,` / `Shift+↓` | 降低推理强度 |
| `Alt+.` / `Shift+↑` | 提高推理强度 |
| `Alt+↑` / `Shift+←` | 编辑最近排队的消息 |

## 输入框（Composer）

| 快捷键 | 作用 |
| --- | --- |
| `Enter` | 提交当前输入 |
| `Tab` | 任务运行中把当前输入排队 |
| `?` | 打开快捷键帮助浮层 |
| `Ctrl+R` | 反向历史搜索（上一条匹配） |
| `Ctrl+S` | 反向历史搜索（下一条匹配） |

## 输入框文本编辑

| 快捷键 | 作用 |
| --- | --- |
| `Shift+Enter` / `Alt+Enter` / `Ctrl+J` / `Ctrl+M` | 插入换行 |
| `←` / `→` / `↑` / `↓` | 移动光标（也可用 `Ctrl+B/F/P/N`） |
| `Alt+←` / `Alt+→`、`Ctrl+←` / `Ctrl+→` | 按词左右移动（也可用 `Alt+B/F`） |
| `Home` / `End`、`Ctrl+A` / `Ctrl+E` | 跳到行首 / 行尾 |
| `Backspace` / `Delete`、`Ctrl+H` / `Ctrl+D` | 删除光标前后字符 |
| `Alt+Backspace` / `Alt+Delete`、`Ctrl+Backspace` / `Ctrl+Delete`、`Ctrl+W` / `Alt+D` | 按词删除 |
| `Ctrl+U` | 删除到行首 |
| `Ctrl+K` | 删除到行尾 |
| `Ctrl+Y` | 粘贴刚删掉的内容（yank） |

## Vim 模式

`/vim` 切换，或自己在 `/keymap` 里绑一个键。进入后：

| 按键 | 作用 |
| --- | --- |
| `i` / `Insert` | 进入插入模式 |
| `a` | 在光标后插入 |
| `A` | 在行尾插入 |
| `I` | 在行首插入 |
| `o` / `O` | 在下方 / 上方开新行 |
| `h` / `j` / `k` / `l` | 左 / 下 / 上 / 右移动 |
| `w` / `b` / `e` | 按词移动 |
| `0` / `$` | 行首 / 行尾 |
| `x` | 删除当前字符 |
| `r` 后接字符 | 替换光标处的一个字符 |
| `s` | 替换当前字符 |
| `f` / `F` 后接字符 | 向后 / 向前查找当前行中的字符（当前 `main`） |
| `t` / `T` 后接字符 | 移到目标字符之前 / 之后（当前 `main`） |
| `gg` / `G` | 跳到输入缓冲区第一行 / 最后一行（当前 `main`） |
| `.` | 重复上一次完整编辑（当前 `main`） |
| `D` / `C` / `Y` | 删除到行尾 / 改到行尾 / 复制整行 |
| `p` | 粘贴 |
| `d` / `y` / `c` | 删除 / 复制 / 修改操作符，可接移动或文本对象 |
| `dd` / `yy` | 删除整行 / 复制整行 |
| `diw`、`ci(`、`ya"` 这类 | 对词、括号、引号等文本对象操作 |
| `Esc` | 取消操作符 / 退出当前状态 |

文本对象支持：`w` / `W`（词）、`(` `)` `[` `]` `{` `}`（括号）、`"` `'` `` ` ``（引号）。

## 翻页 / 列表

| 快捷键 | 作用 |
| --- | --- |
| `↑` / `↓`、`k` / `j` | 逐行滚动 |
| `PageUp` / `PageDown`、`Space`、`Ctrl+B` / `Ctrl+F` | 翻页 |
| `Ctrl+U` / `Ctrl+D` | 半页上下 |
| `Home` / `End` | 跳到顶部 / 底部 |
| `q` / `Ctrl+C` | 关闭当前面板 |
| `Ctrl+T` | 关闭 transcript 面板 |

列表选择器里，`↑↓` 或 `Ctrl+P/N`、`Ctrl+K/J`、`k/j` 移动；`←→` 或 `Ctrl+H/L` 左右移动；`Enter` 确认，`Esc` 取消。

## 审批弹窗

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+A`（或 `Ctrl+Shift+A`） | 展开为全屏详情 |
| `o` | 打开关联线程 |
| `y` | 批准这一次 |
| `a` | 本次会话都批准 |
| `p` | 同类前缀都批准 |
| `d` | 拒绝 |
| `n` / `Esc` | 拒绝并关闭 |
| `c` | 取消 |

## 小贴士

- 输入 `/keymap` 可以查看和改默认键位；`/keymap debug` 会打开按键检查器，用来确认终端实际发给 Codex 的键值。
- `Ctrl+L` 和 `/clear` 行为一致，任务进行中会被禁用。
- `Ctrl+T` 既是打开也是关闭 transcript 面板。
- 如果某个键在终端里被系统吃掉（例如 `Ctrl+S`），直接去 `/keymap` 换成别的键就行。
